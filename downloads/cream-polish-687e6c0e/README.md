These original standalone-game review ROMs need no commercial ROM. Game/art source `687e6c0e999a8df70ef2f7db55f36b9200ddde30`. Build with `BART_CREAM=7`, `8`, `9`, `10` or `11` respectively. Default0 and previous6 reproduce their published ROMs exactly. Current mechanics, original music, Bloom, HUD and other-region artwork are preserved.

In a new game finish the normal three-gift draft, then use the second wall ladder in the Drain for Cream. Existing controls and save layout are unchanged; retain a separate copy of your save for review. `builds.json` gives each exact ROM hash/source; the per-option build files retain flags. `SHA256SUMS` covers all ROMs and the ZIP.

Measured one-row loading adds10–11 VBlanks (~0.17–0.18s); fall/climb simulation timing is unchanged. The gallery records actual input/fixtures, finite QA coverage and visual tradeoffs. These are optional alternatives for review, not a new production default.
