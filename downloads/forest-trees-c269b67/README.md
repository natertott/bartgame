Twelve static native pieces: two forms each at **32×32** and **16×32**, with healthy, sick and dead structure. The user's requested sizes are interpreted as 2×2 and 1×2 gameplay tiles. One shared 16-entry RGB555 palette supports all states together.

The ZIP contains canonical indexed PNGs, RGBA previews, raw 4bpp tiles, a 32-byte palette and the JSON import/anchor contract. It is an **art pack**, not a playable ROM. Actual mGBA review scenes are deliberate test plantings; normal forest/canopy and existing procedural placement remain unchanged.
