# Selected Cream pause map

Contour Folio (#1) layout with Exploded Shelves (#4) colored event markers. The normal build now uses Cream profile12, including the previously selected Weathered Heights terrain.

Enter The Curdled Cream from its Drain ladder. Pause with Start and press R twice from Items to reach the regional map. D-pad selects a room; A zooms; B returns; R opens items; Select returns to the standard menu; Start resumes. The selected map stays fixed.
