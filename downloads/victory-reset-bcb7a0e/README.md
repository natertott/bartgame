# BARTGAME: a fresh run after victory

Sourcebcb7a0e0f0fdb8421c295cbab82f50edb6d88429; normal production build.
ROM9538772bytes; SHA25640c4b7f3738459c7b4fe3866687086fb6441196f4e871ec2f839663cc619e559.

Winning retires the current run. The next title visit or restart offers
New Game instead of continuing a completed forest. Already-finished v1/v2
saves are rejected too. Unfinished saves still Continue normally. The separate
cabinet discovery journal and appearance choices survive victories/new runs.
The three new enemies, original soundtrack and sewer cabinet are included.

Open bartgame-bcb7a0e.gba with mGBA. To use an existing emulator save, copy its
.sav alongside the ROM with the matching basename bartgame-bcb7a0e.sav.
