Open a `.gba` file in mGBA. Controls: D-pad move; A/B/L use their assigned items (B initially sword, L initially shield); R rolls while moving, lifts while standing and throws a carried object; Start opens/closes items, key items and maps. Assign items to A/B/L in the pause menu. Approach a chest from below; walk into a locked gate with a key. The home-screen Options retain the selected independent menu/dialogue frame and palette choices. The ROMs contain the full game, the selected Step-and-cut swing, chosen enemies and broken purple Heart, final Drain and selected interfaces. Native graphics are original; no commercial ROM is required.

New forest features include stronger pulsing purple infection, rounded adjacency, actual canopy occlusion and a real lower root passage, ten wooden chest forms and fifteen forest folk. The root arch has no accessible upper deck. Conditional generation repairs keep approaches and required quest furniture usable. Ordinary builds still use forest0; earlier alternatives remain available.

The ZIP contains the five exact frozen ROMs, a plain-text README, ROM SHA256 sums and five per-ROM frozen build manifests. [Checksums](SHA256SUMS.txt) · [Build manifests](freezes/). Review media and validation reports are in the gallery, outside the ZIP.
