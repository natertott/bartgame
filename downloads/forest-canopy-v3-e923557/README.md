Open a `.gba` file in mGBA. A/B/L use assigned items (B initially sword, L initially shield); R rolls while moving, lifts while standing and throws carried objects; Start opens/closes the item, key-item and map pages. Assign items to A/B/L in the pause menu. Approach chests from below and walk into keyed gates with a key.

The eight treatments rebuild healthy and infected tree crowns while retaining visible living greenery and the accepted grey dead grass. Other environment art stays at previous forest profile6. Bloom, his action timing/physics, selected enemies, items, interfaces, Drain and glitter retain their art. Maze and lantern placement generation are unchanged. A conditional native-body fragment keeps Bloom readable beneath canopy; it does not add new poses. Ordinary builds remain forest0; all previous profiles0–10 remain byte-identical.

The ZIP contains eight exact ROMs, eight frozen build manifests, a plain-text README and ROM checksums. Screenshots, videos and validation reports live in the gallery, outside the ZIP. [Frozen manifests](freezes/)
