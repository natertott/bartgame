Eight native leafy canopy studies

Game/art source e923557aa74b01626f3e599f7c4b50366e096507. Optional profiles11..18; ordinary forest0 remains the default.
Review actual mGBA images and native sprites:
https://github.com/natertott/bartgame/blob/forest-canopy-v3/art-review/forest-canopy-v3/README.md

Open any GBA file in mGBA. A/B/L use assigned items (B initially sword, L shield). R rolls while moving, lifts while standing, throws a carried object. Start opens/closes item/key/map pages.

All eight retain accepted grey grass and the other environment art from old forest profile6. Trees keep living greens beneath different infection treatments. The conditional visibility renderer protects part of Bloom using his existing current-frame pixels; movement/action timing and maze generation are unchanged. These are review alternatives, not an adopted forest choice.
