Ten room-fitted native forest canopy studies
Source: c6dc060043aa6d0d5e2eb43d4d09e97ddf77450a

Each GBA ROM is a different unselected canopy direction (profiles19..28).
Use mGBA or compatible GBA hardware. Start New Game, then climb the Drain's
forest ladder. The normal room generation and progression still apply.
Gallery cameras use disclosed seed/location/inventory fixtures; a new game
does not automatically begin at the gallery camera.

The previous fixed-block canopy studies are rejected. These new native
compositions fit different generated spaces; the default production ROM is
not switched to a candidate. All nineteen historical profiles are byte-exact.
