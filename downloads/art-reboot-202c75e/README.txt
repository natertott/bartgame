BARTGAME — native GBA art reboot

Open bartgame-art-reboot-202c75e.gba in mGBA or on compatible Game Boy Advance hardware.
This is an original standalone game. No commercial base ROM is needed.

Source: 202c75e8ffbfa6079d011a2848f5d9f6305ca9dc
Branch: art-reboot
ROM SHA256: 41dc680068c094416e92152d4c22637c10d6a055d2bee63ce7700c419490e92d

The current game includes the Drain hub and the procedural 5x5 Blighted Forest.
This build replaces all active visual families with native-resolution art:
compact Bloom, tile-sized world drops, shared materials, clear equipment and
interactive scenery, surface glitter, native title, portraits and 24px HUD.
The other eight planned regions are not yet implemented.

D-pad: walk. A/B/L: assigned items (B starts as sword, L as shield).
A: talk. R: roll while moving, lift while still, throw a carried object.
Start: inventory/key items/map; assign items to A/B/L in the inventory.
Approach chests from below. Bombs crack stone; candle burns silk; cape jumps gaps.
The Drain Cap returns to the hub. Existing save structures remain compatible.

Actual mGBA recordings, research, critique, art bible and verification:
https://github.com/natertott/bartgame/blob/art-reboot/art-review/reboot/README.md

Mixed living/blight edges remain visibly angular in some generated layouts;
this is the first complete shared native direction and can be refined further.
