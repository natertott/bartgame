Open one `.gba` in mGBA. Each is the complete standalone game with the same
generation, controls, selected bestiary/Heart, Step-and-cut sword, Drain and
interfaces. No commercial base ROM is needed. Existing saves remain compatible.

These five environment directions are **unselected studies**. The ordinary
build retains production forest0; explicit `BART_FOREST=1..5` builds the choices.
Study portable objects/chests/entrances are shared across areas. Forest NPCs
have matching new portraits. Equipment and pickup icons remain unchanged.

Game/art source [`73df5c1`](https://github.com/natertott/bartgame/commit/73df5c1296f84ac469102c92f106dc9ad17b9a27).
All six main control/study captures pass 3,307 runtime checks across 498 actual
mGBA cases; the independent audit passes 75,315 checks. The linked gallery
separates native source catalogs from actual game timing and records fixtures.

The ZIP contains exactly these five ROMs, instructions, checksums and frozen
input manifests. Individual ROM hashes are listed in [SHA256SUMS.txt](SHA256SUMS.txt).
