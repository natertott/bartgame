# The Drain Trophy Case

Face the cabinet on the north bank and press **A**. Its four tabs record
milestones, item discoveries, creature encounters and Trading Cards. Locked
milestones explain the goal. Undiscovered items, creatures and cards share a
sealed case that keeps their names and artwork hidden.

| Input | Browse | Inspect |
| --- | --- | --- |
| Up / Down | Move one row | Scroll longer notes |
| Left / Right | Jump five rows | Previous / next exhibit |
| L / R | Previous / next tab | Switch tab and return to its index |
| A | Inspect the highlighted exhibit | |
| B | Return to the Drain | Return to the highlighted row |
| Select | Toggle All entries / Found only | |
| Start | Open Run Options | |

The original 240×160 backdrop uses oxidized wood, wine-dark fabric and worn
brass. A gold pointer and a quiet row highlight show focus. An illuminated
plinth carries the current exhibit, with more space for text in inspection.
The browser keeps the selected entry on a five-row page. Inspection keeps
that selection on return and allows longer descriptions to scroll. Run
Options is a secondary action in the index, and B backs out to the case.

## Records and saves

The case records 14 milestones from gameplay, including the Grail, summit and
Four Seals endings, all four trades, the Golden Rope victory, and completing the
card collection. Rank and challenge qualifications use the actual profile
requirements. Items and creatures read the existing discovery journal. Cards
stay discovered after a trade or a new run, while inspection shows how many
copies Bloom currently holds.

The Trophy Case reads the existing profile and journal records. Prior saves
can recover held cards and cards proven by completed trades. Older generic
wins still count toward rank and First Victory. Route-specific trophies are
earned when the game records that route. If a prior save contains an unclaimed
paid bed reward, Continue places it in Bloom's satchel.

The Billious Peddler and the Wizard retain their places. The Forest and Cream
ladders still work, and regional traders stay in their respective areas.
