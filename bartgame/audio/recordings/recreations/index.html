Original mix: retains the supplied performance, voices and instruments, with GBA sampling and output coloration. Instrument rebuild: uses newly synthesized sounds from automatic note/transient inference. Vocals become instrumental lines; dense chords, octaves, articulations and drum details can be missed or misidentified.

All files are captures of the compiled GBA ROMs running in mGBA 0.10.5. Full source intros, fades and silence remain. Physical-console speaker/headphone audio has not been recorded. “Timeless” uses synchronized 32,768 Hz stereo because its complete 65,536 Hz stereo data exceeds one 32 MiB cartridge; the other original-mix versions use 65,536 Hz.

Source and playback

Each compiled ROM contains one complete song version. A plays or stops; START restarts; B stops. The source folder includes the driver, conversion tools, inferred instrumental scores and editable MIDI. Recreating original-mix ROMs requires your uploaded MP3s; synthesizing the supplied instrumental scores requires the documented FluidR3 bank.

FLAC is bit-exact to the unprocessed emulator capture; MP3 is a listening copy. The MP3/FLAC comparisons, editable source and scores are now published in this repository.
