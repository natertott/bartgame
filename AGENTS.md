# Shared game art direction

For artwork, animation, visual layout or art-direction changes in the
standalone game under `bartgame/`, read these before editing:

- `bartgame/docs/art-reboot/ART_BIBLE.md`: the canonical shared art direction.
- `bartgame/docs/art-reboot/ART_DIRECTION_LOG.md`: decisions and their status.
- `bartgame/docs/art-reboot/REFERENCE_REGISTER.md`: reference availability and
  the location of source-specific notes.

Keep the documentation current as part of every art pass. Record what changed,
why, its source or user feedback, affected assets, review evidence and remaining
tradeoffs. Update the art bible when a shared rule changes; record local Drain
or forest choices as local choices. Distinguish an exploratory concept from an
adopted rule so an unselected study does not silently become the game's style.

When using a reference, record its actual filename or URL and relevant pages.
Attribute advice only after reading it. If a required source is unavailable,
record the gap and continue work that does not depend on that source.

Author game pixels at native GBA sizes and colour limits. Preserve currently
requested invariants, including the Drain layout, Bloom and existing glitter,
unless the user authorizes changes to them. Label source assemblies separately
from real emulator captures and keep the build/capture provenance reviewable.

These instructions establish documentation and evidence practices; they do not
add a user-approval requirement. The user's current instructions take priority.
